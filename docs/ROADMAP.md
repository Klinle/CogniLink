# CogniLink 产品定位与功能路线图

> 2026-07 优化升级阶段产出。前置工作（安全修复、RAG 六阶段流水线）见 git 历史。

## 一、项目定位

**一句话定位：把你上传的教材，变成可对话、可练习、可追踪的私人 CS 教练。**

- **目标用户**：计算机专业学生（期末/考研/面试备考）、CS 自学者；次要角色为教师（班级教学）与管理员。
- **核心差异化**：
  1. **Local-first**：BGE-M3 本地嵌入、自带 API Key、数据不出本机——通用 AI 助手给不了的隐私与掌控感。
  2. **结构化学习闭环**：不止"问答"，而是 图谱 → 定位弱点 → 针对出题 → 评测反馈 → 画像更新 的完整循环，六大 CS 领域全覆盖。
  3. **可溯源**：回答基于用户自己的教材并标注来源页码，可信度高于纯 LLM。
- **与通用 ChatGPT 类产品的边界**：凡是"泛聊天"能做好的事不做重复建设；只做与"个人学习资产（文档/图谱/画像/错题）"绑定的能力。

## 二、用户体验主线（学习闭环）

```
导入教材 → 对话理解（带溯源） → 针对性练习 → 错题巩固 → 图谱点亮/画像 → 周期复习
   ↑                                                                    |
   └────────────────────── 复习提醒 / 学习计划 ←──────────────────────────┘
```

当前缺口：闭环右半段（错题巩固、周期复习、计划驱动）基本缺失；左半段（导入/对话/练习）已具备但衔接生硬。

## 三、功能路线（按优先级）

### P0 补齐学习闭环（直接强化定位）

| # | 功能 | 说明 | 现有基础 |
|---|------|------|---------|
| 1 | 诊断式 Onboarding | 首次登录三步：选目标领域 → 上传教材或使用内置知识库 → 10 题诊断测验初始化画像。解决空状态与画像冷启动 | seed 知识库、evaluation_service 出题 |
| 2 | 错题本 + 间隔重复 | 答错题自动进错题本，按 FSRS/SM-2 生成每日复习队列，Dashboard 显示"今日待复习 N 题" | user_lab_submissions、user_collection_exercises |
| 3 | 引用溯源跳转 | 回答中 [来源: 文档, 第N页] 可点击，跳转文档预览并定位页码 | RAG 已输出来源标注、文档预览已有分页 |
| 4 | 会话内出题 | 对话中识别 practice_request 意图后，直接在聊天流中渲染互动练习卡片，做完即评测 | RAG 流水线意图树已识别该意图、exercise-renderer 可复用 |

### P1 练习与检索深化

| # | 功能 | 说明 |
|---|------|------|
| 5 | Pyodide 代码沙箱 | 前端 WASM 真实执行 Python 测试用例，LLM 只负责讲解——评测更准、断网可用，契合 local-first |
| 6 | 学习路径规划器 | 输入目标（如"两周过操作系统"），基于图谱先修关系生成每日计划并联动练习 |
| 7 | 检索质量看板（admin） | 记录检索命中率、零结果查询，指导知识库补充；也是 RAG 流水线的效果回归工具 |

### P2 多用户与教学场景

| # | 功能 | 说明 |
|---|------|------|
| 8 | 教师班级空间 | 共享知识库、作业指派（labs）、班级学情看板（把 admin/students 的 mock 数据变真） |
| 9 | 学习报告与分享 | 周报（学习时长/点亮/正确率趋势）、图谱进度海报导出 |

### P3 体验基建

| # | 功能 | 说明 |
|---|------|------|
| 10 | 移动端适配 + PWA | 复习场景天然碎片化，移动端价值高 |
| 11 | 激励体系 | 连续学习 streak、点亮动效、成就徽章（已有像素风设计语言可延续） |

## 四、工程配套（与功能并行）

- CI（lint + pytest + build）、requirements 版本锁定、.dockerignore
- 前端数据层迁移 react-query（或移除未用依赖）、拆分超大组件、ECharts 按需引入
- Alembic 正式接管 schema 迁移（当前为 init_db 内 ALTER + 容错索引）

## 五、建议节奏

1. **第一里程碑（闭环）**：#1 诊断 Onboarding → #2 错题+间隔复习 → #3 溯源跳转
2. **第二里程碑（深度）**：#4 会话内出题 → #5 Pyodide 沙箱 → #7 检索看板
3. **第三里程碑（扩面）**：#6 路径规划 → #8 班级空间 → #10 PWA

> 三个里程碑已合并为一次统一任务并展开为可执行的任务分解（每个任务含数据库/后端/前端改动、验收标准、依赖与规模，另有 12 项补充功能池 F1–F12）：见 [学习闭环升级任务书.md](./学习闭环升级任务书.md)。产品行为、交互流程与验收口径见 [学习闭环升级PRD.md](./学习闭环升级PRD.md)。
